# ちょる子 トレード・プレイブック（公開情報からの再構成）

> このファイルは AI が「ちょる子ならどうするか」を推論するときの土台です。
> 本人が公開インタビュー・著書抜粋で語った内容を、ルールの形にまとめ直しています。
> 各ルールには出典と確度を付けています。
> - **確度A**: 本人の発言として一次・準一次の記事で確認できたもの
> - **確度B**: 二次記事（まとめ・解説）経由で、本人の発言と食い違いがないもの
> - **確度C**: 公開情報からの推定。本人は言っていないので、検証して書き換える前提のもの
>
> 新しい発言や取引を見つけたら `python -m choruko note` で記録し、
> `python -m choruko distill` で `learned.md` に追記して育ててください。

## 0. プロフィール（推論の前提）

- X: [@kabu_st0ck](https://x.com/kabu_st0ck)。二児の母で会社員。投資を本業にしていない。
- 2011年、240万円（記事により234万円）で株主優待目当てに投資を開始。オリエンタルランドを保有した。
- 2019年、オリエンタルランドを売って約1,500万円にし、現金500万円を足して計2,000万円を**東京エレクトロンに集中投資**した。そのTEL株を担保に**信用取引で東エレクのデイトレ**を始め、育休中に資産1億円に達した。
- 復職後は時間が取れなくなり、**デイトレから大型株の逆張りスイング**に移った。
- 2025年12月時点の内訳は、**高配当株（守り）1.5億円**と**短期投資枠（攻め）1.6億円**。2026年の報道では資産4〜5億円。
- 大きな損失も経験している。新興株の決算またぎで1日−2,400万円、令和のブラックマンデー（2024年8月）で−5,000万円を損切り、別の日に1日−4,400万円。

## 1. 資金管理：「2つの財布」【確度A】

| ID | ルール |
|---|---|
| M1 | 資金を **守りの財布**（高配当株を長期保有）と **攻めの財布**（短期売買）に分ける。攻めで負けても守りは崩さない。 |
| M2 | 攻めの財布では信用取引（ときにフルレバレッジ）も使う。ただし、2024年8月の5,000万円の損切りの原因は「ポジション過多・損切りの遅れ・暴落初動の見誤り」とされる【確度B】。真似するならレバレッジは落とす。 |
| M3 | 投資は生活のリスク分散の一手段で、本業にはしない。 |

## 2. 銘柄ユニバース【確度A】

| ID | ルール |
|---|---|
| U1 | **時価総額1兆円以上**の大型株が対象。現在は**日経平均採用銘柄**を買う対象にしている。 |
| U2 | 流動性の高い大型株は機関投資家の主戦場。そこに乗る「**コバンザメ**」戦略をとる【確度B】。 |
| U3 | **新興株の決算またぎはしない**（−2,400万円の教訓）【確度A：失敗談として本人が公表】。 |
| U4 | 同じ銘柄に絞り、同じチャートを見続けて値動きの癖を覚える。育休中は東エレクだけをスマホで見ていた【確度A】。 |

## 3. 銘柄選定の流れ【確度B】

1. マクロ環境を把握する
2. その年の**テーマ**を決める（テーマ株は戻りが早く上がりやすい）【確度A】
3. セクターを選ぶ
4. **業界1位の企業**を、**安いとき（逆張り）**に買う

### 本人が挙げたテーマ・注目分野（時点つき）
- 2024年: 半導体（新NISAでも半導体株に照準。日経 2024/2）
- 2025年: AI。メタプラネットの時価総額が1兆円を超えたのを見て「投機資金の多さ」を実感した
- 2026年見通し（マネーポスト 2026年初）: 半導体・AI主導の相場は続く。そのうえで**建設・メガバンク・賃上げ後の消費関連**など内需と**バリュー株への回帰**に注目。高市政権の設備投資減税に期待。日経平均6万8,000円も「あながちあり得ない話ではない」
- キーエンスを高く評価（「キーエンスと結婚したい」JBpress 2026）

## 4. エントリー（買い）【確度A〜C】

## 6. マインド【確度A】

- **「1円を拾う」**: 1日100円生活を経験しており、小さな利益をおろそかにしない。
- 負けを前提に「負け方」を決めておく。数千万円の損失を出しても、ルールどおりに切って次の暴落で買い向かう。
- 勝てる手法は**生活時間とセット**で考える。育休中はデイトレ、復職後はスイング。
- 「豪運系投資家」と自称し、運の要素も認めている。

## 7. 再現性についての注意【確度B】

- 第三者による分析記事（note: カイザー投資）は、本人の手法を「高難度トレード」で「再現性が低い」と評価している。集中投資とレバレッジで大きく増やした面が強い。
- 本人の現在のポジションは、本人が公開しない限り分からない。このツールが出す「ちょる子ならこうする」は、**上のルールを今日の相場に当てはめた推定**であって、本人の売買の再現ではない。
