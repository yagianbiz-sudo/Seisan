# ちょる子の手法カタログ

> ちょる子の売買は「暴落の日に買う」だけではありません。
> 動画202本から抜き出した売買（重複を含めて約420件）を手法ごとに分けると、全体の暴落時の逆張りは約1割でした。
> それ以外の多くは、次の売買で占められています。
> - テーマ株の順張り
> - 決算がらみの売買
> - 個別株の「歪み」の逆張り
> - 先物・オプション
> - 政治イベントや需給イベントへの相乗り
>
> このファイルは、手法ごとに「何を狙うか・どこで入るか・どこで出るか・どこで逃げるか・実例」をまとめたものです。
> 原理（なぜそうするか）は `choruko_principles.md`、数値ルールの一覧は `choruko_kb.md` にあります。
>
> 確度の表記は `choruko_kb.md` と同じです（[V 年-月]＝動画で本人が話した、[B]＝第三者の説明で本人発言と矛盾しない、[解釈]＝分析者のまとめ）。

## 0. 全体像：資金の置き場所と手法の対応

```
資産
├─ 守りの財布（約半分）…… ⑪高配当・長期    対面証券に入れて動かさない
│                         ⑫優待・IPO・応援株（娘の口座など）
└─ 攻めの財布（約半分）
     ├─ スイング（数日〜数週間）…… ①個別の歪み逆張り  ②全体の暴落まとめ買い
     │                               ③テーマ初動の順張り  ④決算プレイ  ⑤パンパカパン押し目
     │                               ⑥イベント相乗り  ⑦需給イベント・アノマリー
     ├─ デイトレ（ボラが大きい時）…… ⑨分足のリバ取り・PTS・市場間の連動
     ├─ 先物・オプション（資産の7〜10%、上限2,000万円）…… ⑧ヘッジ・置いていかれ防止・プレミアム
     └─ 現金（相場で0〜100%に動かす）
勝ち金の逃がし先 …… ⑬米国株・不動産・時計・金
```

本人の言葉では、次のとおりです。
- 「ポートフォリオの半分はもう対面証券で動かさない。もう半分はアクティブにトレードしてる。ボラティリティが大きい時はデイトレードだけ、通常時は数日から数週間のスイング」[V 26-03]
- 「私はトレードしてるのが、基本的には大型の株をテクニカルで売買する方法。銘柄の選び方はトップダウンアプローチ」[V 26-05]
- 「なんか私、売買すごくやるんですよ。売ったり買ったりものすごくするので。ずっと持ちっぱなしっていうのをしない。過熱しすぎてると思ったら手放すし、また下がってきたら買うっていうのを回転させるタイプ」[V 26-09]

## ① 個別大型株の「歪み」逆張りスイング（著書の中核）

| 項目 | 内容 |
|---|---|
| 狙い | 監視リストの大型株に、**理由のない売られすぎ（歪み）**が出た時の戻り。全体の暴落を待たなくてもよい |
| 対象 | 今年のテーマに沿った大型株のリスト（日経225採用、時価総額1兆円級） |
| 入る条件 | 次の4つのうち**2つ以上**が重なり、そこから**反発し始めた**所で入る（落ちている最中には飛び込まない）[B 著書要約]<br>1. 材料なしで前日比−2.5%以上の急落<br>2. 25日線を大きく割り込む<br>3. ボリンジャーバンド−3σにタッチ<br>4. RCI −90%以下 |
| 確認すること | なぜ下がったのかを X で検索する。**不祥事・下方修正など明確な悪材料があれば見送る**。理由がなければ「大口注文による一時的な乱れ」として買い場 [B] |
| タイミング | ①寄り付き前に気配を見る ②仕事の合間のザラ場で、1分足で下げ止まったかを見る [B] |
| 出口 | **買った根拠の歪みが解消したら売る**。−2.5%で買ったなら下げた分が埋まった所、25日線割れで買ったなら25日線まで戻った所。「まだ上がりそう」は根拠のない期待なので、機械的に売る [B]<br>本人: 「ボリンジャーバンドのマイナスσで買い、移動平均線付近やプラス側まで戻したら売る。日足で1〜2週間持つ」[V 26-05] |
| 撤退 | −3σを突き抜けたら（みんなが反発すると思っている線が破られた＝信頼が崩れた）。重大な悪材料が出たら、チャートに関係なく撤退 [B] |
| 本人の発言 | 「1年間のテーマを決めてリスト化してる。何もニュースがないのに−3%とかになってたりすると、大型株だとちょっと異常値。特にニュースがないんだったら、そこで入ったりします。材料が何か分かるまで不安で買えない、とは思わない」[V 25-03]<br>「ずっと下落していた銘柄を買って反発を狙うのが得意」「下がったところで買い、戻したら売るパターンが一番好き」[V 26-05] |
| 実例 | キーエンス（2025/6/9。−2σを上に抜けたのを見て100株、下げて約90株を追加、25日線〜+2σを目標）[V 25-06]、アドバンテスト（ダブルボトムでネックラインを抜けた所）[V 25-12] |

| 項目 | 内容 |
|---|---|
| 狙い | 「〇〇ショック」と後に呼ばれる、年に数回の全面安。群衆が投げている時の戻り |
| 入る条件 | 米国 Fear & Greed 20未満 かつ 日経VI 50〜60超（両方そろう）。日経VI 60超は単独でも |

## ③ テーマ株の初動・モメンタム順張り

| 項目 | 内容 |
|---|---|
| 狙い | その年の大きな資金の流れ。「強いもの、資金がしっかり入ってきているものを買うのが一番効率がいい」[V 26-05] |
| 準備 | **年末年始に今年のテーマを予測**する（日経新聞の展望特集、証券会社のレポート、アナリストの見通し）→ テーマの真ん中にある大型でアイコニックな銘柄をお気に入りに入れる [V 26-05/06]。テーマから周辺へ広げる（AI → データセンター → 電線・建設・素材・電力・ゴム）[V 26-06] |
| 入る条件 | **ニュースで資金が入ってきた初動**。テーマになりそうでも、資金が入らなければ相場にならない。「TSMC の決算が出た後に、他の半導体銘柄が上がっているのを確認してから、大きいところを買う」[V 26-05] |
| 入り方 | 資金が入っている所に「避難させる」。例: SQ の月曜（2026/4/6）に、強かった半導体・電線・キーエンス・キオクシアを買う [V 26-05/10] |
| 出口 | **上値を抜けなくなったら、すぐ**。良い材料に反応しなくなったら、セクターから資金が抜けたと見て引き上げる [V 25-11]。ストップ高になったら確定して、次の勢いのある銘柄へ回す（2026年1〜2月）[V 26-07]。過熱したら手放し、下がったら買い直す |
| しないこと | ストップ高で買ってストップ高で売る、のような追いかけは「私はできない」[V 25-09]。上がりすぎと感じたら乗らない（2026/6の電線）[V 26-07] |
| 実例 | 半導体（2019〜、2025/9〜の買い直し）、電線（住友電工・古河電工・藤倉）、JX金属、キオクシア、金鉱山向けタイヤ（横浜ゴム）、化学セクター |

## ④ 決算プレイ

本人は「決算またぎで2,400万円を失った」人ですが、決算そのものは避けていません。**避けているのは「新興株」を「調べずに」またぐこと**です。

| 型 | 内容 | 実例 |
|---|---|---|
| **④-1 決算ストップ高の押し目** | 決算で評価されてストップ高をつけた銘柄が、地合いなどで下がったら拾う。「基本的には決算でストップ高をつけてたところを中心に。そこから安くなったところを買って、上がるのを待つ」[V 26-02] | 住友電工・JX金属・鹿島（2026/2）、化学セクター（2月決算でストップ高 → 4月に「まだ置いていかれている」として買う）[V 26-04] |
| **④-2 決算前に仕込み、決算で売る** | 決算が良さそうな大型株を前に買い、上がったら売る。「決算の前に買い、上がったら売る（決算ごとに回転させる）」[V 26-05]。「決算期待になる銘柄を中心に買い、決算をまたいで保有する」[V 26-10] | アドバンテスト・TEL（2026/9末、決算またぎ狙い）、化学（「次の決算またぎに行きたい」）[V 26-10] |
| **④-3 決算後のバスケット買い** | 決算で受注増・利益率改善など「良い変化」が出た業種を、業種ごとまとめて買い、次の決算まで待つ [V 26-06] | 工作機械・FA（フィジカル AI。受注+46%）[V 26-06] |
| **④-4 業績は良いのに売られた銘柄** | 業績と株価が食い違ったら拾う。「業績はいいのに売られている銘柄を拾うのが好き。がっつり入れるのはそういう時」[V 26-07] | Sansan・ラクス（「SaaS の死」で売られた所）[V 26-08] |

**決算をまたぐ条件** [V/解釈]
- 大型株であること
- 自分で業績を調べていること
- 分散していること

「決算をまたいで持つ時は必ず調べてから」[V 26-09]、「決算をまたぐ時はある程度分散する」[V 26-09]。

**撤退**: 決算の反応が悪い、またはストーリーが崩れたら切る。

## ⑤ パンパカパン（上昇トレンド中の押し目買い）

| 項目 | 内容 |
|---|---|
| 狙い | 上昇トレンドが続く銘柄の、押し目からの再上昇 |
| 入る条件 | 5日・25日・75日線がそろって右肩上がりで、5日線が25日線に近づいて、交わらずに跳ね返る所 [V 25-12〜26-09]。上放れ並び赤（窓を開けて陽線2本）も「上昇相場のスタート」[V 26-05] |
| 出口 | 5日線を陰線の実体で割ったら（1/3以上）売り。+3σを突き抜けたら一部利確。25日線へのアタックは3回目まで |
| 撤退 | 跳ね返らずに25日線を割る。日経平均のリバウンドに連動しない [V 26-09] |
| 実例 | 日経平均（2025/12）、三菱UFJ（2026/7/1。パンパカパンで買ったが「買われず強くなかった」ので同日に切った）[V 26-09] |
| 由来 | 移動平均線の使い方は相場師朗氏（字幕「相史郎」）から学んだ [V 25-09/12] |

## ⑧ 先物・オプション

本人は「個別株が中心」と言いつつ、先物とオプションを日常的に使っています。トランプ政権の2期目からは、夜間にニュースが多いため再開・強化しました [V 26-01]。

| 型 | 内容 |
|---|---|
| **夜間のヘッジ** | 現物は良い所で入れたので持ったまま、指数の下落に備えて**先物を売る**（ラージ1枚＝現物の約2割分）[V 25-07]。夜に大きく下げそうなら、売りを1〜2枚入れて寝る [V 26-10] |
| **置いていかれ防止** | 日経が上がって現物を減らした後も、**先物を買って最低限の持ち高を残す**。「指数を買うので、半導体を買っているのと変わらない」「先物ならいざという時すぐ逃げられる」[V 26-06〜10] |
| **指数そのものを売買** | 個別株が噛み合わない、ローテーションが速い時は、先物で指数を売買する。「個別株より先物の方が、反発も含めて幅広く取れる」[V 26-07/09]。ダブルトップなど指数のチャートでショート [V 25-11] |
| **先物サンドイッチ** | 先物を買う時に、高めの行使価格のコールを売っておく。上がりすぎた時の損を抑え、時間価値の減少を利益にする [V 25-10] |
| **ショートストラングル** | 遠いコールとプットを両方売り、SQ までの時間価値の減少を取る [V 26-01] |
| **イベントの遠いコール買い** | 政治イベントの時に、少額で（10枚・数十万円）[V 25-10, 26-01] |
| **暴落時のプット** | ボラが高い時のプット買いはあり。少額で、許容範囲の金額にとどめる [V 25-11] |
| **ルール** | 上限2,000万円（超えた分は別の運用へ）[V 25-10]。資産の7〜10% [V 26-05/07]。先物は1枚ずつ建てる。**ボラが高い時のオプション売りは危ない**。片方向だけの持ち高には逆指値を入れる |

## ⑨ デイトレ・短期回転

| 型 | 内容 |
|---|---|
| **分足のリバ取り** | 日経平均採用銘柄で、1分足で急落した所を拾い、戻りで売る。「デイトレしてた時は、分足で見て日経平均採用銘柄のリバ取りをずっとやってました」[V 25-12, 26-05] |
| **ギャップダウンのリバウンド** | 1日1回までなら期待値が高い [V 26-05] |
| **時間帯の癖** | 同じ銘柄を見続けると、時間帯で売り物が出て戻る癖が見つかる（2019年の TEL の14時、2020年の感染者数発表の時間）。消えたらやめる [V 25-07/09] |
| **PTS** | 決算の反応を PTS で取る。日経が急に上がった通知で決算が良かったと分かり、PTS で100株買って売る [V 26-05]。金曜夜の PTS で、原油安の恩恵株（JAL・ANA）を買う [V 26-04] |
| **1泊2日** | 下落中に買い、反発を取って翌日売る（キオクシア、2026/7で+185万円）[V 26-09] |
| **使う時** | ボラが大きい時だけ。ニュースで日足が効かない時ほど分足 [V 26-03/05]。初心者は日経と連動する225採用銘柄から [V 26-05] |
| **目標の置き方** | 年収目標から逆算して、1日に抜く値幅を決める（1,000株×157円）[V 25-07/09] |
| **自覚している欠点** | デイトレで回したキオクシアは、握っていれば1億円だった。「損切りは早いが、含み益を伸ばすのは苦手」[V 26-07/09] |

## 15. 手法を選ぶときの共通ルール

1. **理由と出口を揃える**。どの手法で入ったかによって、出口が決まる
   - ①は歪みが解消したら
   - ③は勢いが止まったら
   - ④は決算の反応で
   - ⑥はイベントの通過で
   - ⑪は配当のストーリーが崩れたら
2. **時間軸を混ぜない**。スイングはチャートと需給、決算をまたぐならファンダ（業績）を調べてから [V 26-09]
3. **大型株中心**。デイトレ・テーマ・歪み、どの手法でも、チャートが効き、すぐ逃げられる大型株を使う
4. **ロットは手法ごとに違う**
   - 遊び（イベントのコール、アクティビスト相乗り、流行りセクター）は小さく
   - 確信のある歪みや暴落は大きく
   - それでも寝られる範囲で
5. **相場が荒い時は、「時間軸を長くして業績で見る」か「分足で値幅を取る」かを決める**。中途半端なスイングはしない [V 26-04]
